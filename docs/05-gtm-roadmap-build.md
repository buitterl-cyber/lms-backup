## 29. SaaS Pricing Strategy

Value-metric = **active learner / year** (with intelligence), tiered by capability. Content is
BYOL or marketplace, priced separately — never bundled, so the intelligence value is explicit.

| Tier | For | Per learner/yr (indicative) | Includes |
|---|---|---|---|
| **Essentials** | SMB | $18–30 | LMS, catalog aggregation, basic reports |
| **Intelligence** | mid-market | $40–70 | + Skills Graph, gap analysis, compliance + cert intelligence, RIYADA AI |
| **Enterprise** | large orgs/MSPs | $80–140 | + SSO/SCIM, career intelligence, AI Knowledge Academy, white-label, API, premium support |
| **Government / Sovereign** | gov/ministries | custom | + data residency/on-prem AI, dedicated tenant, procurement, pro-services |

Add-ons: AI Knowledge Academy (usage), extra AI tokens, ClickHouse analytics seats, PowerBI
connector. Annual contracts, volume discounts, multi-year for gov. Free pilot (1 department,
90 days) to prove a readiness/risk drop — the land motion.

## 30. Revenue Model

Five streams (see doc 00 §3): (1) **intelligence subscription** — primary recurring, 75–85%
margin; (2) **marketplace margin** on content/licensing; (3) **AI Knowledge Academy** usage;
(4) **enterprise/gov platform license + pro-services**; (5) **supply-side listing + rev-share**.
Unit economics target: blended gross margin >70%; net revenue retention >120% via land-and-
expand (compliance → skills → career → AI). LTV/CAC > 4 in enterprise within 24 months.

## 31. Marketplace Strategy

A **skills-aware** enterprise marketplace, not a course store. Sells courses, bundles, learning
paths, subscriptions, corporate packages, licensing, skill tracks, certification tracks. Demand
is generated by the intelligence layer — a buyer arrives because the gap engine matched a need
("you need Terraform → here are 3 options"). Features: reviews, ratings, recommendations, **AI
matching to gaps/roles**, search, faceted filters. Take rate on transactions; providers compete
on quality, not just price, because ranking is skill-fit-weighted.

## 32. Partner Strategy

- **Content providers** (GO1, OpenSesame, MS, AWS, Coursera, LinkedIn, Udemy, Skillsoft,
  O'Reilly, …): integrate via PAL; co-sell; rev-share on marketplace.
- **Certification bodies:** authoritative cert + CPD data; co-branded certification tracks.
- **System integrators / consultancies / MSPs:** resell + implement to gov/enterprise; the
  reseller channel for MEA gov deals.
- **Cloud (AWS/Azure) + regional partners:** marketplace listings, gov procurement vehicles,
  data-residency regions.
- **Universities:** employability/skills tracks; pipeline of certified talent into enterprise.

## 38. MVP Build Plan (first 90 days, concrete)

- **Weeks 1–2:** repo + CI + Keycloak + tenant context + RBAC guards + audit log + Prisma schema
  + RLS migration + seed (one demo tenant/org/dept, roles, a few job roles + skills).
- **Weeks 3–5:** GO1 connector (real OAuth + endpoints) → `syncCatalog` → `Course`/`CourseSkill`
  upsert → Meilisearch index → catalog search UI. Enrollment + progress (pull) + learner home.
- **Weeks 6–8:** Skills Graph seed (ESCO subset) + reconciler (string+embedding) + **gap
  analysis** + Recommendation rows with `reason`. Certification model + **expiry sweep** +
  reminders. Compliance (ISO27001 + GDPR) controls + **green/amber/red** + compliance dashboard.
- **Weeks 9–12:** RIYADA AI v1 (LLM router + RAG over a doc + tools `getSkillGap`/`recommend
  Courses`) + assistant panel. Reporting v1 (PDF/CSV). MS Learn connector. Harden, pilot with one
  friendly customer department.

**MVP definition of done:** an admin connects GO1, imports a department, and the platform
*automatically* shows skill gaps, compliance red/amber/green, and expiring certs, then assigns
the right courses with an explainable "why" — proving the intelligence loop end to end.

## 39. Enterprise Build Plan

On top of MVP: SSO (SAML/OIDC) + SCIM provisioning; advanced scoped RBAC; white-label + custom
domains (wildcard TLS + host-based tenant resolution); data residency per region + optional
dedicated DB/cluster; on-prem/local-model AI for sovereign tenants; SCORM player + xAPI LRS +
LTI 1.3; full compliance framework library; PowerBI/export APIs; SOC2 Type II program; DR
multi-region; partner/provider portals; pen-test + audit. Delivered as a hardening track running
parallel to feature squads, gated by enterprise-readiness checklist.

## 40. Global Expansion Plan

- **Phase A — MEA home base:** Arabic/RTL GA, GCC data residency (me region), gov procurement +
  SI partners, localized compliance (national frameworks), reference gov/enterprise logos.
- **Phase B — Europe:** EU data residency, GDPR/NIS2/DORA depth, EU language packs, compliance-
  led GTM, partner resellers.
- **Phase C — Africa & Asia:** mobile-first/offline emphasis, local providers + payment methods,
  university/employability programs, country-by-country compliance packs.
- **Cross-cutting:** i18n/RTL framework already in core; expansion = add language + compliance
  pack + region + local providers + partners — a repeatable playbook, not a re-platform. Scale to
  1M+ learners is a multi-tenant density + regional-cluster exercise, already in the architecture.
